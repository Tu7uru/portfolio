# ARCHIVE.SYS

The portfolio of Haralambos Varsamis (Tu7uru): a working archive behind a working
screen. A 1984-style CRT boots, and each section of the CV is a floppy disk you
can open. Live at **https://tu7uru.github.io/portfolio/**.

The site is one self-contained HTML page (CSS and JavaScript inlined for a fast
first paint) plus a few static files. It has no runtime dependencies and no
framework. Without JavaScript it shows the whole archive as a plain list.

## Layout

```
content/      the disks: one folder = one disk folder, one .md file = one disk
src/          page template, CSS (one file per UI area), JavaScript (one file per feature)
  manifest.json   order in which the CSS and JS files are joined
tools/
  build.mjs   src/ + content/  ->  docs/index.html   (--watch, --check)
  cms-lib.mjs reads and validates content/, generates the data and the no-JS list
  serve.mjs   local preview under /portfolio/, like GitHub Pages
tests/qa.mjs  Playwright QA suite (layout, navigation, keyboard, a11y, motion, content)
docs/         the published site (GitHub Pages serves this folder)
  index.html  GENERATED by the build: do not edit by hand
  fonts/      self-hosted VT323, Caveat and IBM Plex Sans (SIL OFL 1.1, licences alongside)
  og.png, apple-touch-180.png, resume.pdf
```

`docs/index.html` is committed on purpose: GitHub Pages serves static files from
`docs/` on `main` with no build step, so what is in the repository is exactly
what is live.

## Edit the content

Each disk is a Markdown file with a short front matter. See
[content/README.md](content/README.md) for every field. In short:

```
---
title: Deloitte
period: OCT 2023 — PRESENT
role: Software Engineer, Dynamics 365 F&O · Remote, Greece
tags: X++, Dynamics 365 F&O, SSRS
order: 10
---
One-paragraph summary (the card text).

- Each bullet is a line on the VIEW MORE page.
```

Card buttons follow from the data: an item with bullets gets **VIEW MORE**;
every non-contact card gets **OPEN RESUME**; a `link` adds **REPO** (or **OPEN**
for contacts). The CV itself is `docs/resume.pdf`; replace the file, keep the name.

Deep links: `#skip` (straight to the archive), `#path=PROJECTS/ACADEMIC`,
`#open=themis`, combined as `#skip&path=WORK&open=deloitte`.

## Build, preview, test

Requires Node.js 18 or newer.

```sh
npm run build          # docs/index.html from src/ + content/
npm run watch          # rebuild on every save
npm run check          # validate content/ only
npm run serve          # http://127.0.0.1:8741/portfolio/
npm install            # once, for the QA suite (Playwright)
npx playwright install chromium
QA_ORIGIN=http://127.0.0.1:8741/portfolio npm run qa
```

The QA suite runs several hundred checks across five viewports and takes a long
time (tens of minutes); it exits non-zero when any check fails.

## Deploy

GitHub Pages: Settings, Pages, "Deploy from a branch", branch `main`, folder
`/docs`. Every push to `main` that changes `docs/` is live a minute later.
All asset paths are relative, so the site works under the `/portfolio/`
sub-path. The Open Graph image and canonical URL are absolute
(`https://tu7uru.github.io/portfolio/`); change them in
`src/index.template.html` if the address changes.
