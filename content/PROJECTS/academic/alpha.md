Full compiler pipeline: lexer, parser, semantic analysis, intermediate code, target code generation and a virtual machine.

- A complete compiler pipeline for a small ALU-style language, written in C.
- Front end: lexer and a Bison/Yacc (LR) generated parser.
- Semantic analysis, intermediate code and target code generation.
- Target code executes on a companion virtual machine.
- Built as a university project.
